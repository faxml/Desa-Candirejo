## 📋 Tentang Proyek

Website resmi Desa Candirejo ini dikembangkan dalam rangka program **Kuliah Kerja Nyata (KKN)** sebagai upaya digitalisasi desa dan pemberdayaan UMKM lokal Gunungkidul.

Website dibangun menggunakan teknologi **Single-File HTML** agar mudah di-deploy, dirawat, dan dapat dijalankan langsung tanpa server backend.

---

## ✨ Fitur Unggulan

| Fitur | Deskripsi |
|-------|-----------|
| 🔝 **Navbar Glassmorphism** | Sticky navbar responsif dengan efek blur & hamburger menu mobile |
| 🏞️ **Hero Section** | Banner utama dengan statistik desa (penduduk, luas, dusun, UMKM) |
| 📜 **Profil Desa** | Tab interaktif: Sejarah, Visi & Misi, Struktur Organisasi |
| 🛒 **Katalog UMKM** | 6 produk dengan filter kategori & tombol pesan via WhatsApp |
| 🏔️ **Wisata & Budaya** | 4 destinasi wisata dan tradisi budaya lokal Gunungkidul |
| 📋 **Layanan Administrasi** | 4 jenis layanan surat dengan live search interaktif |
| 📰 **Berita & Agenda** | 3 berita terbaru dengan modal popup |
| 🗺️ **Footer + Maps** | Google Maps embed + kontak lengkap + sosial media |

## 🚀 Cara Menjalankan

### Lokal
```bash
# Cukup buka langsung di browser
open index.html
# atau
double-click index.html
```

### Deploy ke GitHub Pages
1. Push repo ini ke GitHub
2. Masuk ke **Settings → Pages**
3. Source: `Deploy from a branch` → Branch: `main` → Folder: `/ (root)`
4. Klik **Save** → Website live di `https://<username>.github.io/<repo-name>`

## 🛠️ Tech Stack

- **HTML5** — Single-file, tanpa framework backend
- **Tailwind CSS** — via CDN (`cdn.tailwindcss.com`)
- **Font Awesome 6.5** — via CDN (ikon)
- **Google Fonts** — Poppins
- **Vanilla JavaScript** — Filter UMKM, live search, tab switching, WA link, modal
- **Gambar** — Wikimedia Commons (bebas lisensi Creative Commons)
